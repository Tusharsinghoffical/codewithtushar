## 🛡️ Security Hardening & Vulnerability Posture

The application follows defense-in-depth security best practices to protect visitor privacy, prevent clickjacking, and enforce strict content boundaries:

1. **HTTP Strict Transport Security (HSTS):** Enforced in `.htaccess` with `max-age=31536000; includeSubDomains; preload` for full SSL transport protection.
2. **MIME-Sniffing Prevention:** `X-Content-Type-Options: nosniff` header blocks malicious file-type sniffing exploits.
3. **Clickjacking Defense:** `X-Frame-Options: SAMEORIGIN` prevents unauthorized third-party iframe embedding.
4. **Referrer Privacy Protection:** `Referrer-Policy: strict-origin-when-cross-origin` prevents leaking sensitive URL query parameters to external hosts.
5. **Hardware Device Permissions Policy:** Explicitly disables unauthorized device access (`camera=(), microphone=(), geolocation=()`).
6. **Automated Security Verification:** Comprehensive Vitest security suite (`test/security.test.ts`) automatically validates:
   - Zero hardcoded private tokens or live API secrets in client code.
   - Protection rules blocking direct web access to `.env`, `.git`, `package.json`, and `.htaccess`.
   - Balanced, injection-safe HTML structures across all 8 technical blog publications.

## 🚀 Quick Start

### Prerequisites
```bash
Node.js ≥ 18 (Node.js 20 or 22 LTS recommended)
npm or pnpm
```

### 1 · Clone Repository & Install Dependencies
```bash
git clone https://github.com/Tusharsinghoffical/Bussiness-website-main.git
cd Bussiness-website-main

# Install dependencies
npm install
```

### 2 · Configure Environment (`.env`)
Copy `.env.example` to `.env.local`:
```bash
copy .env.example .env.local     # Windows
cp .env.example .env.local       # Linux / macOS
```
Fill in your configuration:
```env
VITE_GEMINI_API_KEY=your_gemini_api_key_here
VITE_WHATSAPP_NUMBER=919876543210
VITE_SITE_URL=https://codewithmrsingh.me
VITE_SECONDARY_SITE_URL=https://codewithtushar.me
```

### 3 · Launch Local Development Server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 4 · Production Build & SSG Generation
```bash
npm run build
```
This triggers Vite compilation followed by `scripts/prerender.js`, generating static crawler-ready HTML files in `dist/`.

### 5 · Preview Production Build
```bash
npm run preview
```

## 🌐 Deployment Guide (Render & Vercel)

This repository is pre-configured for instant zero-hassle deployment on both **Render** and **Vercel** with full Static Site Generation (SSG), SPA routing rewrites, HTTP cache optimization, and strict security headers.

### 🔷 Render Deployment
1. Log in to [Render Dashboard](https://dashboard.render.com).
2. Click **New +** → **Blueprint** and connect your GitHub repository (`Bussiness-website`).
3. Render reads [`render.yaml`](render.yaml) automatically:
   - **Type**: Static Site (`services[0].type: static`)
   - **Build Command**: `npm install && npm run build`
   - **Publish Directory**: `./dist`
   - **SPA Fallback**: `/*` rewritten to `/index.html`
   - **Security Headers & Caching**: Pre-configured in `render.yaml`
4. In the Render Dashboard under **Settings**, configure your custom domains:
   - `codewithmrsingh.me` (Primary)
   - `codewithtushar.me` (Mirror / Secondary)

*(Alternatively, to create manually: Choose **New Static Site**, enter Build Command `npm install && npm run build`, and Publish Directory `dist`).*

---

### ▲ Vercel Deployment
1. Log in to [Vercel Dashboard](https://vercel.com/dashboard) and click **Add New...** → **Project**.
2. Select and import your GitHub repository (`Bussiness-website`).
3. Vercel automatically detects the Vite framework and loads [`vercel.json`](vercel.json):
   - **Framework Preset**: Vite
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`
   - **Clean URLs**: Enabled (`cleanUrls: true`)
   - **Rewrites & Headers**: Pre-configured for SPA routing & security
4. Under **Environment Variables**, optionally set:
   - `NODE_ENV` = `production`
   - `VITE_APP_URL` = `https://codewithmrsingh.me`
   - `VITE_APP_SECONDARY_URL` = `https://codewithtushar.me`
5. Click **Deploy**. Vercel will build and distribute your site globally across its Edge Network.
